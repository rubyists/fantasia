== Decision

Use document attributes for repeated URLs and cross references. Keep the link
target and its text in the attribute. Use the attribute in the document body.

Use Mermaid in `[source,mermaid]` blocks for diagrams. Add prose or a table
when a diagram contains information that readers need without the diagram.

== Rationale

See xref:{document-location-decision}.

Attributes keep long URLs and document paths out of body prose. Mermaid source
stays readable in Git and renders on GitHub.
