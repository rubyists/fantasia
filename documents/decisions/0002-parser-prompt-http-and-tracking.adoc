= ADR 0002: Parser, prompt, HTTP, and tracking contracts
:status: accepted
:date: 2026-09-14

== Decision

YamlElixir/yamerl remains the parser. Fantasia parses maps as keyword entries to retain duplicates,
then normalizes exactly one document to string-keyed immutable data. Duplicate keys and multiple
documents are errors; secrets are never included in parse diagnostics. The full-workflow fixture
pins anchors, merges, scalar types, sequences, and multiline values.

The prompt contract is nested `issue.*` data and real `is_rework` state. The Phase 0 fixture captures
that canonical context shape and review comments, but does not claim to test rendering. Engine
adoption and executable corpus coverage for conditions and the `lower` filter are deferred to Phase
1 because Phase 0 does not render prompts. Python's flat keys and forced false rework flag are
corrections, not compatibility targets.

Req with an injected test adapter is the selected future HTTP boundary. Phase 0 adds no live Linear
client. Fixtures require pagination, `assignee: me`, partial errors, malformed/null nodes, and
authenticated-user scoping before the later adapter is admitted.

Tracking reads both legacy `stokowski:` and versioned `fantasia:v1:` markers, validates embedded
timestamps, and selects the newest timestamp independent of response order. New writes use only the
versioned form. Concurrency is keyed by normalized internal phase names.
